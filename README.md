
# OUR LOVE QUEST ❤️

A private two-person adventure where one person creates
tasks, quizzes, challenges and surprises for their partner.

## Core Flow

LOGIN
↓
CREATE / JOIN
↓
CREATE → BUILD QUEST → DONE → UNIQUE CODE + LINK
JOIN → LINK / CODE → COMPLETE QUEST
↓
CLAIM REWARDS
↓
DONE
↓
CREATOR GETS COMPLETION UPDATE

## Main Requirements

- Email login
- Name
- Character selection
- Create / Join
- Unique adventure code
- Unique join link
- Only ONE Joiner per adventure
- Custom tasks
- Custom quizzes
- Custom questions and options
- Challenges
- Coupons
- Surprises
- Notes
- Letters
- Captions
- Expressions of love
- Progress tracking
- Reward claiming
- Final DONE button
- Creator completion notification
- Responsive on phone, tablet and desktop
